ARTICULO 471.- El procedimiento en el juicio sumario se ajustará a las reglas establecidas para el ordinario con las siguientes modificaciones.
Los términos serán:
I.- Diez días para contestar la demanda;
II.- Otro igual para contestar sobre la compensación o reconvención. Pero éstas no serán admisibles sino cuando proceda también tramitarlas en juicio sumario;
III.- Veinte días para pruebas;
IV.- Tres para alegar; y,
V.- Diez para dictar sentencia.
